# Changelog

All notable changes to **SyncNote** are documented here.

---

## [1.0.0] — 2026-10-18

### ✨ Added
- Accounts with sign-up and login (bcrypt passwords, 30-day JWT)
- Rich-text notes with autosave
- AI-generated note titles from the note's content
- AI chat that uses your notes as context
- Next.js landing page on the same site, with the app at `/app/`

### 🎊 Improved
- Mobile layout with a collapsible sidebar
- Notes moved to MongoDB

### 🐛 Fixed
- Auth race condition
- Mobile menu button
- AI chat broken after Groq retired the original model; the model is now set with `GROQ_MODEL`
