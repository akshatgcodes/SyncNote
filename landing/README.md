# SyncNote — Landing Page

A Next.js (App Router, TypeScript, Tailwind CSS) showcase page for [SyncNote](../README.md), a note-taking app with autosave, AI-generated titles, and a notes-aware AI chat assistant.

This is a standalone marketing/showcase site — the actual SyncNote app (React + Vite client, Express + MongoDB server) lives one directory up and is unaffected by anything in here.

## Run it

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
